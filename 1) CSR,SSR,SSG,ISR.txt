B) Hydration kya hota hai?

Hydration = already rendered HTML ko React ke through interactive banana
Simple flow
1) SSR - SERVER SIDE RENDERING
Server → <h1>Hello</h1> send karta hai

Browser me page dikh gaya ✔️

BUT:

button click work nahi karta
state active nahi hoti
2) Hydration step

Browser me React load hota hai (MEANS REACT JS DOWNLOAD HOTA HAI):

React JS → same component dobara match karta hai HTML ke saath

Phir:

event listeners attach hote hain
useState active hota hai
page interactive ban jata hai
Example samjho
SSR output:
<button>Click me</button>

Is time button bas dikh raha hai.

Hydration ke baad:
React button pe onClick attach karta hai

Ab:
✔ click work karega
✔ state change hoga
✔ UI update hoga

D) ISR (INCREMENTAL STATIC REGENERATION)

ISR kya hota hai?

ISR = Static page ko automatic update karna
Pehle SSG samjho

SSG mai:

Page ek baar build hota

Example:

Product price = ₹100

HTML save ho gaya.

Problem

Baad mai price:

₹120

ho gaya.

Lekin user ko:

abhi bhi ₹100

dikhega.

Kyuki static page old hai.

ISR kya karta hai

ISR bolta:

Thodi der baad page automatically update kar do
Example

Tum bolte: (TUM SET KAR SAKTE HO TIME (REVALIDATE : 60))

Har 60 sec baad update check karo
Flow
1. User ko fast static page milta
          ↓
2. 60 sec complete
          ↓
3. Next.js background me naya HTML banata
          ↓
4. Old page replace ho jata
User ko kya benefit

✔ Fast page
✔ Fresh data bhi milta rahega


****** WORKFLOW OF CSR,SSR,SSG******

1) CSR - Client Side Rendering

User Request
      ↓
Browser gets almost empty HTML
      ↓
JS files download
      ↓
React runs in browser
      ↓
API calls happen
      ↓
HTML/UI generated in browser
      ↓
Page becomes interactive

2) SSR - Server Side Rendering

User Request
      ↓
Server runs React components
      ↓
Server fetches data
      ↓
Server generates HTML
      ↓
Ready HTML sent to browser
      ↓
JS files download
      ↓
Hydration happens
      ↓
Page becomes interactive
     ↓
Browser

3) SSG - Static Site Generation

BUILD TIME:

React components
      ↓
Static HTML files generated
      ↓
Files stored

REQUEST TIME:
User Request
      ↓
Ready HTML file sent
      ↓
Browser shows page instantly
      ↓
JS files download
      ↓
Hydration happens
      ↓
Page becomes interactive

4) ISR - Incremental Static Regeneration

Build time pe static HTML generate
            ↓
User ko ready HTML milta
            ↓
Revalidate time complete
            ↓
Next request pe background me new page generate
            ↓
New HTML replace old HTML
