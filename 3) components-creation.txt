*******************CONTEXT API******************

React ka Context API prop drilling problem solve karta hai.

Matlab:

Data ko directly kisi bhi component me access kar sakte ho without manually props pass karna.

CONTEXT API --- Globally DATA STORE 

CONTEXT API MAI 3 CHEEX BAHUT IOMPORTANT HOTA HAI 

createContext === context create karna 
Provider  === data provide karna 
useContext === Data use karna
